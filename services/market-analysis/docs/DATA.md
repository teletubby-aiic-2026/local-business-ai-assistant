# 공식 자료와 해석 범위

## 출처

| 자료 | 공식 안내 | 사용 |
|---|---|---|
| 추정매출－상권 | [서울 열린데이터광장 OA-15572](https://data.seoul.go.kr/dataList/OA-15572/S/1/datasetView.do) | 업종별 분기 추정매출·분포 |
| 점포－상권 | [서울 열린데이터광장 OA-15577](https://data.seoul.go.kr/dataList/OA-15577/S/1/datasetView.do) | 전체·일반·프랜차이즈·개업·폐업 |
| 길단위인구－상권 | [서울 열린데이터광장 OA-15568](https://data.seoul.go.kr/dataList/OA-15568/S/1/datasetView.do) | 상권 전체 인구 원천 지표·분포 |
| 영역－상권 | [서울 열린데이터광장 OA-15560](https://data.seoul.go.kr/dataList/OA-15560/S/1/datasetView.do) | 공식 상권 목록·공개 경계 |

지도 표시는 NAVER Maps, 주소 좌표 확인은 NAVER Geocoding을 사용합니다. 주소 검색 화면에서 사용자가 선택하는 주소 목록은 Kakao 우편번호 검색 UI를 이용합니다. 외부 서비스의 등록·사용 조건은 각 제공기관의 안내를 따릅니다. 이 저장소가 원천 데이터나 외부 서비스의 재배포 허가를 별도로 부여하는 것은 아닙니다.

## 기존에 검증한 범위

2026-11-04 기록은 2024Q3~2026Q2 연속 8분기를 대상으로 합니다. 점포는 공식 상권 1,650곳·업종 합집합 100개, 추정매출은 62개 업종을 포함했습니다. 원천 행 수는 점포 609,699행, 추정매출 171,435행, 인구 13,189행이었습니다. 모든 상권·업종·분기 조합에 행이 있다는 의미는 아닙니다.

저장소에는 선택 화면에 필요한 공개 업종·역·행정동 목록이 포함됩니다. 통계 원본과 생성 카탈로그는 별도 준비하며, 신규 수집 결과가 위 행 수와 영구히 같다고 가정하지 않습니다.

## 준비와 갱신

`python -m scripts.prepare_data`로 준비 상태를 확인합니다. `--from-dir`은 이미 확보한 공식 원본을 검증해 준비하고, `--collect --periods ...`는 명시한 분기의 공식 자료를 수집합니다. 명시적 준비 명령으로만 자료를 변경하며 앱 조회가 자동으로 수집을 시작하지 않습니다.

준비 명령 전에는 실행 중인 앱을 종료하고, 성공한 뒤 재시작해 새 카탈로그를 읽도록 합니다. 원본 파일은 같은 이름의 다른 내용으로 덮어쓰지 않습니다. 기존 자료의 정정을 반영하려다 충돌하면 기존 원본을 보존한 채 별도 검토와 새 스냅샷 준비가 필요합니다.

원천의 조회 범위·페이지·키·해시·코드·기간·핵심 수치를 검사한 후 분석 카탈로그를 생성합니다. 자료가 없거나 검증에 실패하면 임의 데이터로 대체하지 않습니다. 새 카탈로그에서는 기존 분석 조건을 다시 확인해야 할 수 있습니다. 사용자 프로필 DB는 공식 자료 배포 대상에 포함하지 않습니다.

## 해석 규칙

- 매출은 선택 분기의 상권·업종 추정매출 총액이며 개별 가게 매출이 아닙니다.
- 전체 점포와 일반·프랜차이즈를 구분합니다. 개업−폐업을 점포 수 증감과 같은 값으로 가정하지 않습니다.
- 연령 매출 비중의 분모는 연령이 분류된 매출 합계입니다. 전체 추정매출 대비 분류율도 구분합니다.
- 인구는 업종과 무관한 선택 분기 원천 총지표입니다. 일평균·월평균·고유 방문자·매장 고객 수로 임의 환산하지 않습니다.
- 연령·요일·시간 분포를 조합해 원천에 없는 교차 통계를 만들지 않습니다.
- 분포가 불완전하거나 합계 조건을 만족하지 않으면 비중·순위를 보류합니다. 0분모의 증감률을 0%로 표시하지 않습니다.
- 전분기·전년 동분기는 정확한 대상 기간을 사용합니다. 자료가 없으면 다른 분기로 대체하지 않습니다.
- 2023년 공개 경계가 각 통계분기의 실제 경계와 같은지는 미확인입니다. 경계 명칭 충돌이 확인된 후보는 선택을 제한합니다.

자료 갱신 자동 스케줄, 실시간 상권 감시, 미래 매출 예측, 원인 단정은 포함하지 않습니다.
