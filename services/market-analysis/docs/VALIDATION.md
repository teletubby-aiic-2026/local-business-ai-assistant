# 소스 패키지 검증 기록

검증일: 2026-11-06. 이 문서는 B1~B6 전용으로 정리한 소스 패키지의 결과를 기록합니다. 기존 개발 앱이나 2026-11-04 공개 배포와 동일한 코드 해시라고 주장하지 않습니다.

## 분리 범위

- 기본 분석·비교 계산, 상권·업종·기간 선택과 저장, 지도·주소 기능을 포함했습니다.
- AI 클라이언트·대화/요청 미리보기·모델 호출 제어·이전 앱의 리포트/알림은 제외했습니다.
- 공용 모듈은 기본6과 공식 자료 준비에 필요한 함수만 유지했습니다.
- 앱은 import 시 설정이나 DB를 열지 않으며, 실행 factory에서 설정을 읽고 저장소를 엽니다.
- 개인 서버 IP·SSH/배포 설정, 실제 키·`.env`·사용자 DB·대량 공식 통계 원본을 포함하지 않았습니다.
- 기본6 핵심 계산 모듈과 공개 업종·역·행정동 목록은 기존 배포 원본과 대조했습니다. 화면의 미제공 대화 기능 안내 문구는 현재 분석 기능에 맞게 수정했습니다.

## 이번 패키지의 검사

환경: Windows, Python 3.14.4, Node.js 24.22.1, `requirements.lock.txt` 환경.

| 검사 | 결과 | 범위 |
|---|---|---|
| 원본 없는 source-only Python | 257/257 통과 | 공식 raw·분석 카탈로그 없이 실행, 실패·오류·건너뜀 0 |
| 프런트엔드 Node | 126/126 통과 | 실제 화면 코드의 상태 전이·결과 표시·조건 변경, 네트워크와 지도는 모의 환경 |
| 기존 공식 원본 가져오기 | 성공 | 838개 원본 파일을 검증해 동일 카탈로그 `b1_9485a4a6a185c19bb0cf3982` 재현 |

source-only에는 AI 경로가 로컬·공개 모드에서 모두 없는지, B1~B6 OpenAPI, 세션 분리·수정 충돌·저장 복원, 자료 미확보 처리, 공개 origin·쿠키, Maps 모의 응답과 오류 처리를 포함합니다. 신규 자료 준비 보조명령은 최초 발행·원본 충돌·기본 무호출·기간·페이지·해시 검사로 검증했습니다.

공식 자료 포함 실행은 274.988초였으며, B1 가용성은 81,157개 상권·업종 조합의 1,947,768개 지표·분기 판정을 원본과 독립 대조했습니다. 실행 중 생성한 저장소 174개 중 170개는 메모리, 나머지는 개별 시험의 임시 SQLite였습니다. 이 시간은 해당 검증 실행 기록이며 서비스 응답시간의 보장이 아닙니다.

source-only와 공식 자료 포함 시험에는 겹치는 항목이 있으므로 두 개수를 합산하지 않습니다. API 검증은 내부 테스트 클라이언트를 사용하고 실제 사용자 DB 대신 메모리·임시 DB를 사용합니다. 외부 네트워크와 실제 설정 로드는 검증기에서 차단합니다. Windows의 테스트 클라이언트가 필요로 하는 내부 loopback 소켓은 허용된 실행 환경에서 검증했습니다.

## 자료 준비와 검증의 제한

`--from-dir`의 기존 공식 원본 가져오기는 실제 보유 원본으로 실행했습니다. `--collect`의 새 API 수집 경로는 모의 시험으로 검증했으며, 이번 소스 정리 작업에서 서울시 자료를 다시 다운로드하거나 NAVER 유료 API를 호출하지 않았습니다.

공식 자료 회귀는 2024Q3~2026Q2의 기존 8분기 스냅샷과 대표 상권·업종·과거 실패 사례를 기준으로 합니다. 임의의 분기 목록에 대한 범용 검증이나 모든 조합의 화면 검증으로 표현하지 않습니다. 새로운 자료로 바꿀 때는 자료 범위와 독립 기대값을 함께 검토해야 합니다.

현재 소스 패키지를 공개 서버에 재배포한 기록은 아닙니다. 이번 작업은 GitHub 소스 공유를 위한 분리·검증이며 기존 운영 서비스는 변경하지 않았습니다.
