# local-business-ai-assistant

소상공인 AI 비서 프로젝트의 기능별 소스 저장소입니다.

| 모듈 | 범위 | 실행 안내 |
|---|---|---|
| 상권분석 | 상권 설정, 추정매출, 점포, 유동인구, 상권 비교, 기간 변화 | [services/market-analysis](services/market-analysis/README.md) |

상권분석 모듈은 기본 6개 기능을 독립 실행할 수 있도록 구성했습니다. 현재 업로드 범위에는 대화형 AI, 리포트, 알림 기능이 포함되지 않습니다. 공식 통계 원본·개인 설정 DB·API 키는 저장소에 포함하지 않으며 모듈 안내에 따라 별도로 준비합니다.

관련 조사·범위: [이슈 #8](https://github.com/teletubby-aiic-2026/local-business-ai-assistant/issues/8)
