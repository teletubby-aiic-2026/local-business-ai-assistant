# 장승배기역 4번 — 상권 전반의 하락 근거

> **보조자료: 하루 전체 시간대 지표입니다.** 팀에서 요청한 저녁 시간대 매출 비교와 선정 근거는 [저녁 매출 비교 문서](c4-evening-sales-comparison.md), 데모 연결용 지표는 [공용 스냅샷 JSON](../data/scenario/snapshot_2026Q2.json)을 참고하세요. 아래 하루 전체 수치를 저녁 매출 하락률로 사용하지 않습니다.

서울시 상권분석자료에서 **장승배기역 4번(동작구, 상권코드 3110826)**은 매출·유동인구·점포 수가 함께 감소한 상권 사례입니다. 2026년 2분기를 전년 같은 분기와 비교했으며, 특정 업종을 지정하지 않았습니다. 매출은 **하루 전체 시간대**를 합한 분기 추정매출입니다.

작성일: 2026년 11월 9일. 분석 자료 범위: 2024년 3분기~2026년 2분기(8개 분기).

## 핵심 비교

| 지표 | 2025년 2분기 | 2026년 2분기 | 증감 | 전년 동기 대비 |
|---|---:|---:|---:|---:|
| 관측 업종 합산 추정매출 | 5,417,755,303원 | 3,903,643,361원 | −1,514,111,942원 | **−27.95%** |
| 8개 분기 공통 11개 업종 추정매출 | 5,352,755,025원 | 3,870,549,621원 | −1,482,205,404원 | **−27.69%** |
| 유동인구 지표(원천값) | 444,715명 | 378,751명 | −65,964명 | **−14.83%** |
| 관측 업종 합산 점포 수 | 243개 | 227개 | −16개 | **−6.58%** |

변화율 = `(당기 값 − 전년 동기 값) / 전년 동기 값 × 100`. 문서에는 소수 둘째 자리까지 표시하고, JSON에는 계산값을 보존했습니다. 이전 값이 0이면 변화율은 `null`이며, 자료 없음과 0을 구분합니다.

## 선정 이유

매출뿐 아니라 상권 전체의 유동인구 지표와 점포 수도 감소했습니다. 특히 추정매출은 아래 네 분기 모두 전년 같은 분기보다 낮고, 감소 폭도 커졌습니다. 이는 직전 분기만 비교하는 것보다 계절 변동의 영향을 줄여 보여 주는 근거입니다. 계절성이나 다른 요인을 완전히 통제했다는 뜻은 아닙니다.

| 기준 분기 | 관측 업종 합산 매출의 전년 동기 대비 변화율 | 공통 11개 업종 매출의 전년 동기 대비 변화율 |
|---|---:|---:|
| 2025년 3분기 | −3.28% | −2.65% |
| 2025년 4분기 | −7.87% | −7.31% |
| 2026년 1분기 | −20.39% | −19.33% |
| 2026년 2분기 | −27.95% | −27.69% |

매출이 매 분기 직전 분기보다 내려갔다는 주장은 아닙니다. 위 표는 모두 **전년 동기 대비** 비교입니다. 선정은 이 상권의 하락 징후를 설명하는 사례 선정이며, 서울 전체 하락률 1위 또는 통계적 유의성을 검정한 순위가 아닙니다.

## ‘업종 구분 없이 전체’의 의미

대표 지표는 각 분기에 이 상권에서 **관측된 모든 매출 업종의 합계**입니다. 특정 업종을 골라 제외하지 않았습니다. 다만 공개 자료에서 관측되지 않은 업종까지 포함한 모든 사업체의 실제 총매출을 뜻하지 않습니다.

매출 자료의 관측 업종은 2025년 2분기 14개, 2026년 2분기 12개입니다. 이전에 관측된 일반의류(25,593,314원)와 화장품(9,656원)은 당기 자료에 없습니다. 이 누락을 매출 0 또는 폐업으로 해석하지 않았습니다.

집계 범위 변화의 영향을 확인하기 위해 **8개 분기에 모두 관측된 11개 업종**으로 별도 비교했습니다. 같은 업종 구성에서도 27.69% 감소해, 관측 업종 수의 변화만으로 설명되는 하락은 아닙니다. 이 보조 지표는 ‘최근 두 분기의 공통 업종’과도 구분됩니다.

공통 업종: 한식음식점, 분식전문점, 호프-간이주점, 커피-음료, 예술학원, 스포츠 강습, 미용실, 네일숍, 피부관리실, 세탁소, 슈퍼마켓. 업종 코드와 8개 분기 원값은 [분석 JSON](../data/scenario/jangseungbaegi_3110826/analysis.json)에 있습니다.

점포 자료의 관측 업종은 62개→61개입니다. 빠진 자동차부품 업종은 이전 점포 수가 실제 0개여서 공통 업종으로 비교해도 243개→227개입니다. 모든 점포 원천 행에서 `전체 = 일반 + 프랜차이즈`가 일치했습니다. 매출과 점포의 업종 범위가 다르므로 두 값을 나눠 점포당 매출로 제시하지 않습니다.

[원천 발췌 JSON](../data/scenario/jangseungbaegi_3110826/source_rows.json)에는 매출 102행, 유동인구 8행, 점포 492행(합계 602행)과 상권 메타데이터 1행이 있습니다. 지표 원본 88개 파일에서 해당 상권에 필요한 행·열만 발췌했습니다. 전체 서울 원본이나 API 요청 URL은 포함하지 않습니다.

발췌에는 원천 파일명, 서비스명, 출처 URL, 수집 시각, 원본 파일·응답과 대조하기 위한 SHA-256을 보존했습니다. 발췌만으로 전체 서울 API 수집의 완전성을 다시 검증할 수는 없습니다. 스크립트는 제공된 발췌에서 계산을 재현하고, 상권·분기·중복·숫자 누락·점포 합계를 검사합니다.

[하루 전체 지표 요약 JSON](../data/scenario/jangseungbaegi_3110826/all_day_snapshot_2026Q2.json)은 위 표의 변화율 4개와 기준 분기·비교 분기·출처를 담습니다. 이 보조자료의 재현 스크립트는 이 파일만 읽고 쓰며, 데모 연결용 공용 스냅샷을 변경하지 않습니다.

저장소 루트에서 Python 3.9 이상으로 실행합니다. 표준 라이브러리만 사용하며 API 키·추가 설치·네트워크가 필요 없습니다.

```sh
python -B -X utf8 scripts/reproduce_jangseungbaegi.py
python -B -X utf8 -m unittest discover -s tests -p test_jangseungbaegi_evidence.py -v
```

첫 명령은 저장된 분석·지표 요약을 재계산해 일치 여부를 검사하며 파일을 바꾸지 않습니다. 원천 발췌를 변경한 뒤 출력 JSON을 갱신하려면 첫 명령에 `--write`를 붙입니다. 기존 파일에 다른 `snapshot_id`가 있으면 모든 쓰기 전에 중단합니다. 재생성 후에는 문서 수치와 선정 근거도 다시 검토해야 합니다.

## 해석 범위

- 추정매출은 상권의 업종별 통계이며 개별 가게의 실제 매출·배달 매출이 아닙니다.
- 유동인구는 `TOT_FLPOP_CO` 원천값입니다. 고유 방문객, 매장 고객, 일평균으로 바꾸지 않았고, 이 발췌에서 시간 집계 방식을 별도로 검증하지 않았습니다.
- 상권 코드·명칭은 8개 분기에서 같지만 기간별 지도 경계의 동일성은 검증하지 않았습니다.
- 매출·인구·점포 감소의 원인, 모든 업종의 하락, 현재 실시간 상황을 단정하지 않습니다. 통계 기준 시점은 **2026년 2분기**입니다.
