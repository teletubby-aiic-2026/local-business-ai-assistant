# C4 — 후보 5곳의 저녁 추정매출 비교와 데모 상권 선정

팀 요청인 **후보 상권 3~5곳의 2025년 2분기와 2026년 2분기 저녁 추정매출 비교 → 하락 상권 1곳 선정 → 스냅샷 JSON**에 맞춰 PR #17을 보완한 자료입니다. 선정 상권은 **장승배기역 4번(3110826)**이며, 추천 카드의 근거는 **17~24시, 비교 두 분기 공통 12개 업종의 전년 동기 대비 19.31% 감소**입니다.

작성일: 2026년 11월 9일. [서울시 공식 추정매출·상권 자료](https://data.seoul.go.kr/dataList/OA-15572/S/1/datasetView.do)의 보유 원본을 사용했습니다. 새 API 수집·숫자 보정·모델 호출은 하지 않았습니다.

## 저녁과 비교 기준

- 팀 카톡은 ‘저녁’의 정확한 시간 경계를 지정하지 않았습니다. **이번 분석에서는 17~24시**로 정의했습니다. 공식 `TMZON_17_21_SELNG_AMT`와 `TMZON_21_24_SELNG_AMT`의 합입니다. 17~21시와 21~24시 결과도 별도 보존했습니다.
- 2025Q2와 2026Q2의 **같은 시간대·같은 상권 코드**를 비교합니다. 금액 단위는 원이며 분기 누적 추정매출입니다. 일평균·실시간·개별 가게 실제 매출이 아닙니다.
- 특정 업종을 사전에 지정하지 않았습니다. 주지표는 각 상권에서 **두 분기에 모두 관측된 업종의 교집합**을 고정해 합산합니다. 업종 구성 변화의 영향을 줄이기 위한 기준입니다. 각 분기 관측 업종 전체 합계도 함께 제시합니다.
- 미관측 업종을 0원·폐업으로 바꾸지 않습니다. 변화율은 `(2026Q2 − 2025Q2) / 2025Q2 × 100`이며 전년 값이 0이면 `null`입니다. JSON에는 반올림 전 값을, 문서에는 소수 둘째 자리 값을 씁니다.

## 후보를 고른 방법

기존 PR #17의 **장승배기역 4번을 앵커**로 유지했습니다. 나머지 4곳은 매출 결과를 보기 전에, 공식 영역 메타데이터에서 같은 **동작구·골목상권** 중 대표 좌표의 제곱거리가 가까운 순서로 고정했습니다. 거리가 같으면 상권 코드 오름차순입니다. 앵커 외 동작구 골목상권 34곳이 후보군입니다.

공식 좌표계의 원래 X/Y 값으로 순서만 정했습니다. 미터 거리·도보 거리·상권 경계의 인접성을 주장하지 않습니다. 앵커는 이전 분석에서 이미 선택됐으므로 후보 전체가 무작위 사전 표본이었다고 주장하지 않습니다. 이 비교는 **주변 5곳의 시나리오 사례 선택**이며 서울 전체 대표 표본·하락률 1위 검증이 아닙니다. 선정 규칙과 동작구 골목상권 메타데이터는 발췌 JSON에 포함되어 재현할 수 있습니다.

## 선정 결과와 원래 PR #17의 차이

관측 업종 합계와 공통 업종 합계가 모두 감소한 후보 중 **공통 업종 17~24시 변화율이 가장 낮은 곳**을 선택했습니다. 동률은 상권 코드 오름차순입니다. 장승배기역 4번은 공통 12개 업종의 저녁 매출이 **2,778,386,532원 → 2,241,971,854원(−19.31%)**입니다. 관측 업종 전체 합계도 **2,802,261,417원 → 2,241,971,854원(−19.99%)**으로 감소했습니다. 17~21시만 비교해도 공통 업종 기준 −20.49%로 하락이 유지됩니다. 이는 통계적 유의성 검정이나 하락 원인 규명이 아닙니다.

장승배기역 4번의 관측 업종은 14개→12개입니다. 당기에 관측되지 않은 일반의류·화장품은 0원으로 대체하지 않았습니다. 이번 **두 분기 공통 12개 업종**은 기존 문서의 **8개 분기 공통 11개 업종**과 다른 집합입니다. 기존 하루 전체 매출 하락률 27.95%·27.69%를 저녁 매출 변화율로 사용하지 않습니다.

기존 하루 전체 분석·원천 발췌는 보조자료로 보존했습니다. 기존 4개 스냅샷은 [하루 전체 보조 스냅샷](../data/scenario/jangseungbaegi_3110826/all_day_snapshot_2026Q2.json)으로 옮겼고, 공용 [snapshot_2026Q2.json](../data/scenario/snapshot_2026Q2.json)은 이번 저녁 지표 1건만 담습니다. 기존 재현기와 테스트도 보조 스냅샷 경로를 사용합니다.

## 전달 파일과 사용

- [스냅샷 JSON](../data/scenario/snapshot_2026Q2.json): C1 `AnalysisSnapshot`의 10필드를 사용하는 레코드 목록, 1건. `value=-19.306697315937033`, `unit=%`, `basis_quarter=2026Q2`, `compared_with_quarter=2025Q2`, `is_estimate=true`.
- [분석 JSON](../data/scenario/evening_sales_2026Q2/analysis.json): 후보 5곳, 세 시간 범위, 관측·공통 업종의 전후 금액·변화율·선정 결과.
- [원천 발췌](../data/scenario/evening_sales_2026Q2/source_rows.json): 후보 5곳의 원천 75행과 메타데이터. 금액·업종·분기·상권·6개 시간대 필드를 보존합니다.

화면·대본에서 사용할 문장 예시: **“이 상권의 저녁 시간대(17~24시) 추정매출이 전년 동기보다 19.31% 감소했습니다. 비교 두 분기 공통 12개 업종 기준이며, 기준은 2026년 2분기·출처는 서울시입니다.”** 이 데이터는 쿠폰 효과나 매출 감소 원인을 입증하지 않습니다. 카드의 추천 행동은 C5 규칙으로 결정합니다.

## 출처와 재현 검증

보유 `VwsmTrdarSelngQq` 공식 원본은 두 분기 각각 22페이지이며 전체 원천 행 수는 2025Q2 21,452행, 2026Q2 21,133행입니다. 원본 파일·payload 해시, 성공 응답, 비샘플·전 서울 범위, 페이지 연속성 및 `(상권, 업종)` 중복을 확인한 뒤 해당 5곳의 75행만 발췌했습니다. 각 후보 행의 6개 시간대 매출 합계와 하루 전체 분기 매출도 일치합니다.

발췌에는 파일명·수집 시각·공식 출처 URL·전체 파일/payload SHA-256을 보존합니다. 원본 전체를 포함하지 않으므로 **발췌만으로 서울 전체 수집의 완전성·원본 진위를 독립적으로 증명하지는 못합니다.** 해시는 보유 원본과의 대조용이며 서울시 전자서명이 아닙니다. 인증키·요청 URL·개인 경로는 포함하지 않습니다.

저장소 루트에서 Python 3.9 이상으로 실행합니다. 표준 라이브러리만 사용하며 키·서버·네트워크가 필요 없습니다.

```powershell
python -B -S -X utf8 scripts/reproduce_c4_evening_sales.py
python -B -S -X utf8 scripts/reproduce_jangseungbaegi.py
python -B -S -X utf8 -m unittest discover -s tests -p 'test_*evidence.py' -v
python -B -S -X utf8 -m unittest discover -s tests -p 'test_c4_evening_sales.py' -v
```

기본 명령은 파일을 바꾸지 않고 저장된 결과와 비교합니다. 의도적으로 원천 발췌를 바꾼 뒤 해당 결과를 재생성할 때만 `reproduce_c4_evening_sales.py --write`를 사용합니다. 다른 스냅샷 ID나 다른 분석 스키마가 있으면 쓰기 전에 중단합니다. 재생성 뒤에는 문서·대본 숫자도 다시 검토합니다.

공식 공개자료의 추정치이며 실제 개별 음식점 실적과 구분합니다. 각 후보의 업종 구성은 서로 다르고, 기간별 지도 경계의 동일성은 별도로 검증하지 않았습니다.
